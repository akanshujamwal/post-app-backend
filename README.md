# Post App Backend
---
A RESTful API backend for managing user posts, built with Node.js, Express, and MongoDB. Supports creating posts with images and captions, and retrieving all posts from the database.

## Features

- Create a new post with an image and caption
- Retrieve all posts stored in the database
- MongoDB Atlas integration via Mongoose
- Environment-based configuration using `.env`

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- [npm](https://www.npmjs.com/) v9 or higher
- A [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) cluster (or local MongoDB instance)

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd post-app-backend

# Install dependencies
npm install
```

### Environment Variables

Create a `.env` file in the project root:

```env
MONGO_URL=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/<database>
```

| Variable | Description | Required |
|---|---|---|
| `MONGO_URL` | Full MongoDB connection string | Yes |

> **Important:** Never commit your `.env` file or expose your database credentials. The `.env` file is listed in `.gitignore` by default.

### Running the Server

```bash
# Start development server (with auto-reload via nodemon)
npm start
```

The server will start on **port 3005**.

```
Server is running on port 3005
MongoDB connected
```

## API Reference

### Base URL

```
http://localhost:3005
```

---

### Create a Post

**`POST /addPost`**

Creates a new post with an image and caption.

**Request Body**

```json
{
  "image": "base64_encoded_string_or_url",
  "caption": "Your caption here"
}
```

| Field | Type | Description |
|---|---|---|
| `image` | `String` | Image data (base64 or URL) |
| `caption` | `String` | Text caption for the post |

**Response — `201 Created`**

```json
{
  "message": "Post created sucessfully"
}
```

**Example (cURL)**

```bash
curl -X POST http://localhost:3005/addPost \
  -H "Content-Type: application/json" \
  -d '{"image": "https://example.com/photo.jpg", "caption": "Hello World!"}'
```

---

### Get All Posts

**`GET /getPosts`**

Returns all posts stored in the database.

**Response — `200 OK`**

```json
{
  "message": "Post feched sucessfully",
  "notes": [
    {
      "_id": "664f2a...",
      "image": "https://example.com/photo.jpg",
      "caption": "Hello World!"
    }
  ]
}
```

**Example (cURL)**

```bash
curl http://localhost:3005/getPosts
```

**Collection:** `post`

| Field | Type | Description |
|---|---|---|
| `_id` | `ObjectId` | Auto-generated by MongoDB |
| `image` | `String` | Image data or URL |
| `caption` | `String` | Post caption text |

## Postman Collection

A ready-to-use Postman collection is included at:

```
postman/Post App Backend.postman_collection.json
```

Import it into [Postman](https://www.postman.com/) to test all endpoints immediately. Set the `url2` collection variable to your base URL (e.g., `http://localhost:3005`).
